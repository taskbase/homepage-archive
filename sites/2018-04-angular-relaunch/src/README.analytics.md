# Google Tag Manager

- https://tagmanager.google.com
- To track clicks uniquely, give all buttons and links ids
  - Prefix the links with the name of the component!

## General Concept
- Triggers: e.g. click or scroll can be a triggers
- Tags: send information to analytics systems (e.g. GA)

## Firing Google Analytics EVENTS
- EventCategory: use page url
- EventAction: click, scroll, ...
- EventLabel: if possible dom-element-id
- EventValue: Must be positive integer, you can just set it to 1
