We constantly try to push the limits of technology...

...therefore we see it as our duty not to support Internet Explorer.

Internet Explorer was discontinued by Microsoft in 2015.*

Please use a modern browser such as Chrome, Firefox, Safari, Edge or Opera to view our website.



* Since Microsoft doesn't add new features to Internet Explorer anymore, it effectively means it lacks all recent developments of web technologies. Supporting Internet Explorer therefore implies, that we are stuck with technologies from 2015 or before, which prevents us from providing the best user experience possible. We find this unfair for all the users with modern browsers.
