Taskbase Homepage Museum

Every taskbase.com homepage we could dig up, from the Internet Archive and from git history. Visuals only — forms, analytics and backends are stripped or dead. Click a card to open that homepage.

NOT TASKBASE — 2002, the domain's previous owner

prehistory: 2001 – 2004 (not Taskbase)
okHand-written HTML 4, <font> tags, ColdFusion (tasklogin.cfm)wayback

Not Taskbase. A curiosity: taskbase.com had an owner before us, and this is what the domain served. Taskbase the company was founded in 2015 and did not get taskbase.com until 2016 (see the 2016-01 card for the last page the old owner served). The archive holds exactly four captures of www.taskbase.com from 2001-2004 and this is the only one with real content: a staff login for some unrelated task tracker, posting to tasklogin.cfm. The other three are a GDEX Internet Services "Under Construction" placeholder (2001-02), a meta-refresh to a bare IP (2003-11), and an "off-line for maintenance" page carrying a US phone number (2004-10). Nothing archived between 2004 and 2016, so the trail from that owner to ours is blank. Renders exactly as captured, no assets to lose — the page never had any. The login form posts nowhere. A muted badge at bottom right repeats the "not Taskbase" warning for anyone who opens the page on its own.

Taskbase 2018 — app landing / Acadilly handover

2018-04 – 2018-08
okAngularJS 1.5.9 + Angular Material 1.1.3 inside the acadilly webapp, ui-router 0.3.2, Bootstrap 3.3.7, SCSSgit

Not the marketing site — the landing page the old Taskbase *app* served while it was being renamed to Acadilly, telling teachers to move to acadilly.com. Kept because it is the last thing taskbase-the-app showed visitors; the earlier 'Your cloud for teaching material' hero survives under src/.../tb-landing/deprecated/ and is not the one rendered here. Real AngularJS boot: index.html is the era's components/app/app.html, the module is the era's assets/js/app.js, ui-router enters the era's landing state, and the era's own controllers and components drive it, so every ng-switch / ng-if / ng-repeat evaluates (verified: injector present, appReady true, zero console and $injector errors, no overflow at 1440 and 390, mobile menu opens on click). Serving from localhost selects the default taskbase whitelabel branch, so no brand flag is overridden and the acadilly / e-maths / mathbridge markup is untouched. The era's TypeScript is rebuilt into its own assets/js/generated/scripts.js by build/transpile.py, which runs the real tsc 2.8.3 inside the headless Chromium on this box with the era tsconfig — nothing retyped by hand. There is no sass here, so the CSS is flattened from the era SCSS by build/build_css.py via tools/scss_flatten.py, which drops @include mixin bodies; the script expands @extend, evaluates lighten()/darken() and hoists nested @media after their base rules. The backend is an $httpBackend decorator in museum/museum-glue.js, fixtures shaped from the era's own servlets and none of it displayed, so no copy is invented. Trackers, the MathJax load and the Google Charts fetch are stripped; libs.css, libs.js and icomoon were never committed, and libs.js is reconstructed from the versions pinned in package.json. No archive capture of this page exists, so the layout is inferred from source alone — the one corroboration is the 2018-08-29 acadilly.com capture, which returns this same app.html shell. Two live-clock artefacts are the era code's own behaviour, not museum edits: the footer copyright year comes from new Date(), and 'all rights reserved' goes through TranslationService, which reads navigator.language.
